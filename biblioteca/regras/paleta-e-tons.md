# Paleta e tons

Regra número 1: **nunca invente uma cor nova.** Se a cor não está nesta página, ela não entra no site. É isso que faz um site parecer feito por profissional em vez de "montado aos poucos".

## As cores da casa

| Cor | Código | Quando usar |
|---|---|---|
| Verde principal | `#1d6b57` | Botão da ação mais importante, links, aba ativa |
| Verde escuro | `#155244` | Só quando o mouse aperta o botão verde |
| Verde claro | `#e8f5f0` | Fundo suave de ícone, destaque leve |
| Verde vivo | `#2a9d8a` | Só em degradê, junto com o verde principal |

## As 3 regras que fazem parecer caro

**1. Só um verde cheio por tela.**
Se tudo é importante, nada é. Escolha a ação principal da tela — só ela ganha o botão verde. O resto vira botão branco ou sem moldura.

**2. Espaçamento sempre múltiplo de 4.**
4, 8, 12, 16, 20, 24, 32, 40. Nunca 7, nunca 13, nunca 25. O olho não percebe conscientemente, mas sente quando está errado.

**3. No máximo 3 sombras no site inteiro.**
Sombra leve (cartão parado), sombra média (botão), sombra forte (janela flutuando). Mais que isso vira bagunça.

## Como usar cor para dizer coisas

- Verde = está tudo certo, resolvido, em dia
- Amarelo = precisa de atenção logo, vence hoje
- Vermelho = problema, atrasado, vai apagar algo
- Azul = só informação, nada urgente
- Cinza = desligado, arquivado, sem importância agora

**Importante:** nunca use SÓ a cor para dizer algo. Quem não enxerga bem a diferença entre verde e vermelho fica perdido. Por isso todo selo do catálogo tem cor **e** palavra escrita.
