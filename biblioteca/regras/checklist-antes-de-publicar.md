# Checklist antes de publicar

O Claude roda isto **sozinho**, sem você pedir, toda vez que mexer no visual do site. Você não precisa decorar nada — está aqui só para você saber o que está sendo conferido.

## 1. Dá pra ler?

- [ ] Texto principal com no mínimo 14px (nunca 11px "pra caber mais coisa")
- [ ] Cor do texto contrasta o suficiente com o fundo (regra oficial: 4,5 para 1)
- [ ] Texto cinza claro nunca é usado para informação importante
- [ ] Linha de texto não passa de ~75 letras (senão o olho se perde)

## 2. Dá pra clicar?

- [ ] Todo botão tem no mínimo 44 x 44 pixels no celular (tamanho do dedo)
- [ ] Botões não ficam colados um no outro (mínimo 8px entre eles)
- [ ] Todo botão muda de aparência quando o mouse passa por cima
- [ ] Quem usa só teclado consegue ver onde está (contorno de foco visível)

## 3. A pessoa entende o que aconteceu?

- [ ] Salvou → aparece confirmação
- [ ] Deu erro → aparece o que fazer, não só "erro"
- [ ] Está carregando → aparece que está carregando
- [ ] Lista vazia → explica por que está vazia e o que fazer
- [ ] Ação que apaga coisa → pede confirmação antes

## 4. Funciona no celular?

- [ ] Testado em 375px de largura (iPhone) — nada cortado, nada saindo da tela
- [ ] Testado em 768px (tablet)
- [ ] Tabelas rolam para o lado em vez de quebrar a tela
- [ ] Nada exige "apertar duas vezes" ou "arrastar com dois dedos"

## 5. Está bonito de verdade?

- [ ] Espaçamentos são sempre múltiplos de 4 (4, 8, 12, 16, 24...) — é isso que dá o "ar de caro"
- [ ] Cantos arredondados iguais nas peças do mesmo tipo
- [ ] No máximo 3 sombras diferentes no site inteiro
- [ ] Só UM botão verde cheio por tela (a ação principal)
- [ ] Nenhuma cor inventada fora da paleta de `paleta-e-tons.md`
- [ ] Nenhuma fonte nova sem motivo

## 6. Não quebrou nada?

- [ ] Aberto no navegador de verdade e clicado de ponta a ponta
- [ ] Nenhum erro vermelho no console do navegador
- [ ] Nenhuma imagem ou arquivo faltando
- [ ] Site continua abrindo com duplo clique e funcionando sem internet

## 7. Você continua dona

- [ ] Nada novo exige programa rodando
- [ ] Nada novo exige internet para funcionar
- [ ] Você continua conseguindo trocar textos sozinha
